TZ-GUITAR

2010–2026

NAME

tz guitar - read guitar tablature

SYNOPSIS

tz guitar [infile [outfile]]

DESCRIPTION

Preprocess input for the program tz mel to allow for guitar tablatures. Filenames default to /dev/stdin or /dev/stdout. The dash (-) is a shorthand for the default value.

SYNTAX

The syntax of infile is as described in tz-mel(1), with the following exception: If a line contains at least two vertical bars (|), they act as separators between regions. If a region contains at least one of the commands |, -, _, N, ~, ^, S, Z, T, and X, it represents one bar/measure. Here, these commands act differently and the U of an ensuing Un can be omitted. The bar duration, defined beforehand via the |n command, is evenly distributed among the enclosed characters. The hyphen-minus (-), the underscore (_), and N represent a string at rest (a pause); the tilde (~), the circumflex (^), S, Z, T, and X represent a vibrating string (sound is played), just like all other characters, beyond their usual meanings. Here, ^ (hammer-on or pull-off), S/Z (slide down/up), and T (tap) imply a legato transition to the ensuing note, while X (rhythm) ends the previous note and plucks the string (or beats the drum) again. N (no sound) could denote a muted string. Lines with tablature that are not separated by an empty line start at the same point in time. This is realized via the M0 mark, which shall thus not be used.
